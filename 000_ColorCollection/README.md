# フォトグラファーのためのカラーコレクションレシピBOOK — XMP制作

## Batch 01 / Recipes 001–014

本パッケージは、ユーザー提供PDFの掲載内容をもとに、画面表示・本文に明記されたLightroom調整値をXMP化した初回バッチです。

- 対象: Recipe 001–014（Basic 001–010 / Variation 011–014）
- XMP: 14ファイル
- CSV: 抽出値、掲載ページ、注記
- Lightroom Classic / Lightroom向けの汎用XMP

## 抽出ルール
- 数値が明記・画面表示されている項目のみ設定。
- 数値指定のない「色温度を上げる」等は推測で数値化しない。
- 人物の肌などへの局所補正・補正ブラシは汎用プリセットに含めない。
- トーンカーブの百分率座標は0–255に換算。
- 特定バージョンに依存するカメラプロファイルは指定せず、白黒変換など汎用処理に置換した場合はCSVに注記。
