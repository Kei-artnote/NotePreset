# Fujifilm Pro 400H 風プリセット 特色・使い方ガイド

元の「Fujifilm Pro 400H.xmp」の設定値を解析し、ブラッシュアップした6種類のプリセットの一覧です。
保存先: Googleドライブ「MadeKei」フォルダ

> 数値は設計上の想定値です。実際の写真での確認は行っていないため、仕上がりを見て微調整してください。

---

## 1. 一覧と使い分け早見表

| プリセット | 変化の強さ | 一言でいうと | 向いている被写体・シーン |
|---|---|---|---|
| **v2** | 弱 | 元プリセットを整えた忠実な改良版 | 元の雰囲気を残したいとき、風景・スナップ |
| **Natural** | 弱 | 色をできるだけ残す自然寄り | スナップ、日常風景、色を保ちたい写真 |
| **v3** | 中 | 人物の肌に効かせた標準版 | ポートレート全般、日中の人物 |
| **Natural v3** | 中弱 | 自然さを保ちつつ肌が明るくなる | 人物スナップ、普段使いの人物 |
| **Soft** | 中 | 明るく淡い、柔らかい描写 | 日中の風景、淡い雰囲気の写真 |
| **Soft v3** | 強 | 最も明るく淡い。人物向けの最強版 | ポートレート、ウェディング風、逆光・明るい屋外 |

迷ったときは、人物なら **v3**、風景・スナップなら **v2** か **Natural** から試すと分かりやすいです。

## 2. 元プリセットの特徴（分析結果）

名前の先入観なしに設定値だけを見た結果です。

- 明るく平坦な階調: 露光 +0.48、コントラスト −19、ハイライト −50、シャドウ +33
- 色を抑えた仕上がり: 緑（彩度 −24、色相 −20）、青（彩度 −18）、オレンジ（彩度 −15、輝度 +10）
- 明部は暖色、暗部はシアン寄りの色かぶり（ハイライト色相45、シャドウ色相190）
- 粒子はやや目立つ（量21、サイズ25）
- 弱点: トーンカーブが初期値のままで効果なし、ホワイト −5 で透明感が落ちる、緑が黄色寄りに濁りやすい

## 3. 各プリセットの詳細

### v2（元の改良版）
- **特色**: 元の方向性を保ちながら、ホワイトを上げて透明感を出し、緑の黄色寄りを弱めた版。変化は穏やかです。
- **使いどころ**: 元のプリセットを置き換える基準版。風景、スナップ、変化を控えめにしたいとき。
- **注意**: 人物では変化が小さく感じることがあります（そのため v3 を作成）。

### Natural（自然寄り）
- **特色**: 彩度を落としすぎず、自然な彩度を +4 にして色を残す版。緑は輝度を下げて落ち着かせ、青は穏やかに。
- **使いどころ**: 日常スナップ、街歩き、色の情報を保ちたい写真。
- **注意**: 全体の変化は最も控えめです。

### v3（人物向け標準版）
- **特色**: 肌色のレッド・オレンジの輝度を上げて彩度を下げ、肌が明るく淡くなるようにした版。中間調に暖色、暗部にシアンを入れ、トーンカーブで黒を持ち上げハイライトを丸めています。
- **使いどころ**: ポートレート全般。まず試す1本として向いています。
- **注意**: 肌が白っぽくなりすぎる場合は、オレンジの輝度を下げて調整します。

### Natural v3（人物向け・自然寄り）
- **特色**: Natural の自然さを保ちつつ、肌の明るさと暖色を v2 より効かせた版。コントラストは低めに抑えています。
- **使いどころ**: 人物スナップ、家族写真、普段使いの人物写真。
- **注意**: 変化は v3 より穏やかです。

### Soft（明るく淡い）
- **特色**: 露光 +0.45、コントラスト −20、ハイライト −55 で、明るく柔らかい描写にした版。淡い色彩と透明感を重視しています。
- **使いどころ**: 日中の風景、明るい場所のスナップ。
- **注意**: 暗い写真に使うと眠い印象になりやすいです。

### Soft v3（最も淡い人物向け版）
- **特色**: 露光 +0.50、コントラスト −28、黒の持ち上げ 0→20。オレンジの輝度 +20、ハイライトの暖色を強めて、肌がふんわり明るくなる版。テクスチャ・明瞭度も −12 で柔らかさを強調。
- **使いどころ**: ポートレート、逆光、明るい屋外、淡い雰囲気を狙う写真。
- **注意**: 白飛びや平坦さが出やすいので、露光を −0.3 程度まで下げて調整してください。

## 5. 使い方

### 取り込み
- Lightroom Classic: 現像モジュールのプリセットパネルの「+」から「プリセットを読み込む」で `.xmp` を選択
- Lightroom（クラウド版）: プリセット画面のメニューから「プリセットをインポート」
- 取り込むと「Color Negative」グループに表示されます

### 基本の流れ
1. 先に**露出とホワイトバランスを整える**（プリセットの効き方が大きく変わります）
2. プリセットを適用する
3. **適用量（Amount）**で強さを調整する（100%が基準。弱めたいときは60〜80%）
4. 最後に露光・肌の色（オレンジの輝度・彩度）だけ微調整する

### 調整のコツ
| 症状 | 調整 |
|---|---|
| 肌が白っぽい・のっぺりする | オレンジの輝度を −5〜−8、露光を −0.2〜−0.3 |
| 肌が青白い | シャドウのシアン彩度を下げる、ハイライトの暖色を上げる |
| 肌が黄色すぎる | ミッドトーンの色相を 25 → 15 付近、またはオレンジの彩度を上げる |
| 緑が汚く見える | 緑の色相を −6 → 0、彩度を少し戻す |
| 眠く見える・メリハリ不足 | コントラストを +5〜+10、黒レベルを下げる |
| 全体が淡すぎる | 適用量を下げる、または彩度を +5 |

### 注意点
- 元の写真が暗い・コントラストが低い場合は、先に露出を調整してから適用する
- 逆光や白い服の人物では、ハイライトが飛びやすい（Soft系で顕著）
- カメラ側のプロファイルや撮影時のホワイトバランスによって、色の出方が変わる

## 6. 迷ったときの選び方

```
人物を撮った？
├─ はい → 淡く柔らかくしたい？
│        ├─ はい → Soft v3（強すぎたら v3）
│        └─ いいえ（自然に） → Natural v3
└─ いいえ（風景・スナップ）→ 色をしっかり残したい？
         ├─ はい → Natural
         └─ いいえ → v2（淡くしたいなら Soft）
```
