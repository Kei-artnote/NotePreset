# Portra 400 プリセット使い分けガイド（MadeKei Kodak）

Kodak Portra 400 の特徴（自然な肌色、色のまとまり、ISO 400 としての細かな粒状性、幅広い条件への対応）を参考に作った 4 種類のプリセットです。単純な「暖色フィルム」にはせず、**肌色・ハイライト階調・色のまとまり・粒状性**を軸にしています。

> ※ 数値は設計値です。実写での微調整を前提にしてください。

## 1. 早見表

| | v2 | Standard | Soft | Warm |
|---|---|---|---|---|
| 一言で | 万能・少しフィルムらしい褪せ | 基準・最も中立 | 淡く柔らかい | 暖かく穏やか |
| 黒（カーブ左端） | 0→9 | 0→6 | 0→16 | 0→7 |
| 白（カーブ右端） | 255→251 | 255→252 | 255→246 | 255→251 |
| Vibrance / Saturation | +5 / −5 | +4 / −4 | +2 / −10 | +6 / −2 |
| Contrast / Highlights / Shadows | −5 / −20 / +16 | −3 / −15 / +12 | −10 / −30 / +20 | −3 / −18 / +14 |
| Clarity / Texture | −3 / −1 | −2 / 0 | −8 / −4 | −2 / 0 |
| 影の色 | シアン寄り 195° | ほぼ中立 200° | 淡い青 210° | 冷たさを残す 205° |
| 中間調の色 | 32°・3 | 30°・2 | 25°・2 | **38°・10（暖色）** |
| ハイライトの色 | 50°・8 | 50°・6 | 55°・4 | **52°・12（クリーム）** |
| 粒状（量/サイズ/粗さ） | 17/23/55 | 15/22/55 | 14/26/45 | 16/24/52 |

## 2. 迷ったときの選び方

1. **まず Standard を当てる。** 基準なので、他との差も分かりやすい。
2. 光が弱い、曇り、日常の淡い雰囲気 → **Soft**
3. 夕方、街並み、旅行、人物スナップで暖かさがほしい → **Warm**
4. Standard より少しフィルムらしい褪せや、影のシアンがほしい → **v2**

## 3. 各プリセットの特色と使いどころ

### Portra 400 v2
- **特色**: 前に作った Refined 版を、新しい方針（肌色の自然さ・階調優先）に合わせて見直したもの。影はわずかにシアン寄り、ハイライトにほんのり暖色が乗る。Standard より少しだけ褪せていて、粒状もやや強め。
- **向く場面**: 人物、日常、旅行など幅広く。「少しフィルムっぽくしたい」とき。
- **注意**: 影のシアンは弱いが、緑や青の多い風景では色被りに見えることがある。

### Portra 400 Standard（基準）
- **特色**: 階調はゆるい S 字で穏やか。ハイライトを維持し、彩度を上げすぎない。肌（オレンジ）は色相・彩度とも触らず、明るさだけ +4。
- **向く場面**: 人物、ポートレート、ファッション、迷ったときの最初の一枚。
- **注意**: 変化は控えめ。人物では「色が変わった」より「落ち着いた」に見えやすい。

### Portra 400 Soft
- **特色**: 黒を一番持ち上げ（0→16）、白も 246 で止めて、ハイライトを丸く柔らかくする。彩度を全体に下げ（Saturation −10）、色の移行をなだらかにする（ブレンド 70）。Clarity −8・Texture −4 で描写も柔らかい。
- **向く場面**: 曇り、日陰、逆光、淡い光の風景、ふんわりした日常スナップ。
- **注意**: 黒が浮くので、コントラストの強い硬い光や、締まりのほしいシーンでは眠く見える。そのときは Blacks を −5〜−10。

### Portra 400 Warm
- **特色**: 中間調に暖色（38°・10）、ハイライトはクリーム（52°・12）。カーブも中間調だけ R を少し上げ、B を少し下げて暖める。一方で、影は B を持ち上げて冷たさを残し、黄ばみを防ぐ。赤・オレンジの彩度を丁寧に上げ、緑はくすませる。
- **向く場面**: 夕景、街並み、旅行、人物スナップ。
- **注意**: 元のホワイトバランスがすでに暖かい写真では黄色く寄る。そのときは Amount を 70〜80 に下げるか、色温度を少し下げる。

## 4. 使い方のコツ

1. **先に露出とホワイトバランスを整える。** プリセットはどれも露出・色温度を触っていない。Portra 系は少し明るめのほうが映えやすい（目安は +0.3〜+0.7EV。画像による）。
2. **強さは Amount で調整する。** 目安は 70〜130。
3. **人物で色の変化が弱いとき**: Amount を 130〜150 にする。より確実には、中間調の彩度（Standard 2→6、Warm 10→16）やオレンジの彩度を上げる。
4. **プリセットの重ねがけは避ける。** 同じ項目を上書きするので、後に当てたもので上書きされる。
5. **仕上げ**: プリセット適用 → 露出・WB → 肌など部分のマスク調整、の順にする。

## 5. こう変えたいときの調整先

| 変えたいこと | 触る項目 |
|---|---|
| もっと柔らかく | Clarity / Texture を下げる、トーンカーブ右端を下げる |
| 黒を締めたい | Blacks を下げる、カーブ左端を下げる |
| 肌を明るく | HSL オレンジの輝度を上げる |
| 肌の赤みを抑える | HSL 赤の彩度を下げる、オレンジの色相を少し黄寄りに |
| 暖かさを強める | カラーグレーディング中間調の彩度、ハイライトの彩度を上げる |
| 影の黄ばみ・緑被りを避ける | 影の色を 200〜210° に、シャドウティントを調整 |
| 粒を目立たせる | 粒状の量を上げる（粗さは 45〜55） |

## 6. 向かない場面

- 蛍光灯や混合光で緑被りしている写真（先にホワイトバランスを補正）
- 強い夕焼けや派手な色を見せたい写真（全体に彩度を抑えている）
- 黒を締めたいドラマチックな写真（Soft は特に不向き）

## 7. 技術メモ

- プロセスバージョン 15.4、グループ名「MadeKei Kodak」
- カラーグレーディングは旧式のスプリットトーン項目で保存しているため、新しい Lightroom では「カラーグレーディング」パネルに反映される
- ソート名の番号（00 v2、01 Standard、02 Soft、03 Warm）でプリセット一覧の並び順を固定している
