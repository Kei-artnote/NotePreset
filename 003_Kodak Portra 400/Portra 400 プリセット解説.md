# Kodak Portra 400 プリセット解説（MadeKei Kodak）

Kodak Portra 400 の特徴（自然な肌色、色のまとまり、ISO 400 としての細かな粒状性、幅広い条件への対応）を参考にした再設計版の 3 種です。**3 種は色違いではなく、それぞれ別の役割**を持たせています。

> ※ 数値は設計値です。実写での微調整を前提にしてください。

## 共通ルール

- **ホワイトバランスは触らない**（色温度・色かぶり補正は未設定。撮影時の設定を維持）
- **露出は固定補正しない**（写真に応じて調整できるよう、Exposure は未設定）
- **肌色を最優先**にして HSL を調整（オレンジの色相は 0、彩度は −1〜+2 に抑える）
- 緑・青の調整は控えめにして、Portra らしい自然さを保つ
- 粒子は控えめ（量 10〜12、サイズ 20〜21、粗さ 55）

## 1. 役割の違い

| | 01 Natural | 02 Bright | 03 Color |
|---|---|---|---|
| 役割 | 基本の描写 | 明るい光の中の Portra | 色彩表現を少し積極的に |
| コントラスト | 自然（−2） | やや穏やか（−6） | やや強め（+4） |
| ハイライト | 階調維持（−12） | 明部を丁寧に調整（−22、Whites +2） | 階調維持（−12） |
| シャドウ | 自然（+10） | やや持ち上げる（+18） | 適度な締まり（+4、Blacks −2） |
| トーンカーブ（黒→白） | 0→4 / 255→253 | 0→8 / 255→253、中間調 +8 | 0→4 / 255→253、中間調の傾き強め |
| HSL | 自然な色再現 | 淡い色彩（全体に彩度を下げる） | 色相・彩度を積極調整 |
| カラーグレーディング | 控えめ | 明部を暖かく（52°・10） | 色かぶりを抑制（影 2、光 3） |
| Vibrance / Saturation | +3 / −3 | +2 / −8 | +6 / −2 |
| 粒子 | 10/20/55 | 10/20/55 | 12/21/55 |

## 2. 各プリセットの特色と使いどころ

### 01 Portra 400 Natural（基準）
- **特色**: 階調はゆるい S 字で、白は 253 で止めてハイライトを維持。肌（オレンジ）は色相・彩度とも触らず、明るさだけ +3。緑と黄は彩度を少し落として色を整理。Texture +2 で細部を残す。
- **向く場面**: 人物、ポートレート、日常。迷ったときの最初の一枚。
- **注意**: 変化は控えめ。人物では「色が変わった」より「落ち着いた」に見えやすい。

### 02 Portra 400 Bright
- **特色**: 中間調をカーブで持ち上げ（128→136）、シャドウも +18 で潰さない。ハイライトは −22 でしっかり回復し、Whites +2 で白の抜けを保つ。彩度は全体に抑えて淡い色彩に。ハイライトだけ暖かく（52°・10）して、明るい部分の色を自然に整える。
- **向く場面**: 日中の人物、旅行、屋外スナップ。
- **注意**: 中間調が明るいため、すでに明るく撮れた写真では白っぽくなる。そのときは露出を少し下げる。

### 03 Portra 400 Color
- **特色**: 赤の彩度 +6・色相 +2、オレンジは肌優先で彩度 +2・明るさ +4。緑は色相 −6・彩度 −6・明るさ −5 で整理して深みを出し、青は色相 −4・明るさ −6 でやや深い空に。色ごとの分離感を出しつつ、カラーグレーディングは弱めて色かぶりを抑える。
- **向く場面**: 街並み、自然、旅行、色彩を生かしたスナップ。
- **注意**: 緑が深くなるぶん、暗い森や木陰では沈みやすい。そのときは Shadows を +10 程度に。

## 3. 選び方

1. 迷ったら **Natural**
2. 明るい日中、屋外、淡く軽い雰囲気 → **Bright**
3. 色の違いを見せたい街並み・自然 → **Color**

## 4. 使い方のコツ

- 先に露出とホワイトバランスを整える（プリセットはどちらも触らない）
- 強さは Amount で調整（目安 70〜130）
- 人物で効きが弱いときは Amount を 130〜150 に、または Color を使う
- プリセットの重ねがけは避ける（同じ項目が上書きされる）
- 仕上げは、プリセット → 露出・WB → 肌などのマスク調整の順

## 6. 技術メモ

- プロセスバージョン 15.4、グループ名「MadeKei Kodak」
- カラーグレーディングは旧式のスプリットトーン項目で保存しているため、新しい Lightroom では「カラーグレーディング」パネルに反映される
- ソート名の番号（01 Natural、02 Bright、03 Color）で一覧の並び順を固定
