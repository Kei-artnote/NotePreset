# Kodak Tri-X 400 プリセットシリーズ 使い分けガイド

Tri-X 400 の描写（締まった黒、力強い階調、目に見える粒、赤フィルター的な色の明暗）をベースにした Lightroom プリセット集です。

- 白黒版：3種（01 Standard / 02 Pushed / 03 Soft）
- 最初に作った白黒版：4種（Refined / All-Round EI400 / Push EI800 / Push EI1600）
- 彩度落とし版（Desat）：3種
- 方向性別：5種（Hard Flash / Deep Shadow / Fine Grain / Vintage Print / Red Filter）

> 数値は設計値です。実際の写真での見え方は未確認なので、使いながら調整してください。

---

## 1. 2つの方式の違い

| | 白黒版（01〜03・最初の4種） | 彩度落とし版（Desat・方向性別5種） |
|---|---|---|
| 仕組み | 白黒変換（Treatment=Monochrome）＋Adobe Monochrome プロファイル | カラープロファイルのまま彩度 -100 |
| 色別の明るさ調整 | グレイミキサー | HSL の輝度スライダー |
| 向く写真 | カラー・白黒どちらでも | カラー写真のみ |
| 強み | 色別調整の幅が広く、仕上がりが安定 | カラーに戻しやすい、プロファイルを保てる |
| 注意 | 適用するとプロファイルが白黒用に切り替わる | 計算が異なるため、白黒版と空や緑の濃さが少し違う |

どちらも強制ではなく、適用後にプロファイル欄でカラーに戻せます（戻すと白黒用の色別調整は効かなくなります）。

## 3. 各プリセットの特色と使い方

### 01 Standard（基準版）
- **特色**：オーソドックスな Tri-X。自然なモノクロ階調、適度に締まった黒、中間調の厚み、控えめな粒。
- **設計**：トーンカーブはシャドウをわずかに沈め、ハイライトをわずかに持ち上げるゆるいS字。赤+20、青-25で、肌は明るく空はやや沈む。
- **向く被写体**：迷ったときの標準。日常、スナップ、人物、風景全般。
- **使い方**：まずこれを当て、足りない要素を他のプリセットや個別スライダーで足す。

### 02 Pushed（増感現像イメージ）
- **特色**：黒をより深く、ハイライトを際立たせ、中間調のコントラストも強める。粒は目立たせる。
- **設計**：コントラスト+45、黒-40、白+20、粒70。カーブもシャドウを強めに沈める。シャープ・明瞭度も上げて、粒に輪郭が埋もれないようにしている。
- **向く被写体**：スナップ、夜景、ストリート、建築。
- **注意**：暗部がかなり重くなる。夜景では黒を -30 前後まで戻すと使いやすい。

### 03 Soft（階調と余白を生かす）
- **特色**：穏やかなコントラスト、ハイライトの階調重視、シャドウを潰さない、粒は控えめ。
- **設計**：ハイライト-30、シャドウ+30。カーブの黒を6、白を250に置いて、潰れと白飛びを避ける。
- **向く被写体**：ポートレート、風景、建築、静物。
- **注意**：黒が完全には沈まないので、もう少し締めたい場合は黒を -15 程度まで下げる。

### Hard Flash（ハイライトと黒の対比）
- **特色**：フラッシュの直射光のような硬い対比。白と黒の両端を強く振る。
- **設計**：コントラスト+50、白+30、黒-45、ハイライト+10。カーブは急なS字。
- **向く被写体**：人物、夜のスナップ。
- **注意**：ハイライトが飛びやすい。人物では白を +15 程度まで下げ、肌の階調を残す。

### Deep Shadow（暗部の存在感）
- **特色**：シャドウを深く沈めつつ、暗部のテクスチャを残して存在感を出す。
- **設計**：シャドウ-35、黒-40、カーブの暗部を沈める。テクスチャ+10、明瞭度+8。緑・アクア・青を暗くして、植物や空も重くする。
- **向く被写体**：都市、建築。
- **注意**：暗い被写体だと潰れやすい。その場合は露出を少し上げてから適用する。

### Fine Grain（粒を抑え、解像感重視）
- **特色**：粒をほぼ見せず、細部のくっきり感を優先する。
- **設計**：粒量8、サイズ20。シャープ50（半径0.8、ディテール40、マスク25）、テクスチャ+10、ノイズ除去10。
- **向く被写体**：風景、静物。
- **注意**：フィルムらしさは薄くなる。粒を足したいなら粒量を 20 前後まで上げる。

### Vintage Print（古い印画紙風）
- **特色**：黒を少し浮かせ、白も抑えて、退色した印画紙のような雰囲気にする。
- **設計**：カーブの黒を18に浮かせ、白を244に抑える。ハイライトとシャドウにごく弱い暖色（彩度6と4）を足している。
- **向く被写体**：日常、ポートレート。
- **注意**：純粋な黒が出ないので、締まった階調が欲しい用途には向かない。純白黒にしたい場合は、カラーグレーディングの彩度を0にする。

### Red Filter（赤フィルター風の空）
- **特色**：赤フィルターを使ったように、青空が濃く沈み、雲が浮き上がる。
- **設計**：赤+60、オレンジ+45に対して、青-70、アクア-50、パープル-40。かすみ除去+8、明瞭度+10で雲の立体感を出す。
- **向く被写体**：空、雲、風景。
- **注意**：肌が明るく飛びやすい。人物に使うなら赤を +40 前後まで下げる。

### 最初の4種（Refined / All-Round EI400 / Push EI800 / Push EI1600）
元の「Kodak Tri-X 400.xmp」を分析して作った、白黒版（白黒変換＋グレイミキサー）のシリーズです。4種とも色別の設定は共通で、赤+25、オレンジ+20、黄+5、緑-15、アクア-10、青-35です。違いはコントラスト・黒・粒・カーブにあります。

| | 位置づけ | トーンカーブ（暗部→明部の形） |
|---|---|---|
| Refined | 元プリセットの欠点を直した基本形 | ゆるいS字（64→58、192→200） |
| All-Round EI400 | ISO 400 基準の標準 | 暗部をわずかに沈め、明部を持ち上げる |
| Push EI800 | 1段増感のイメージ | 暗部を沈め、明部を持ち上げる |
| Push EI1600 | 2段増感のイメージ | 暗部を最も強く沈め、中間調も持ち上げる |

#### Refined
- **特色**：元プリセットの弱点（シャープ不足、黒の潰れ、直線のカーブ）を直したもの。粒は残しつつ輪郭を立てる。
- **設計**：シャープ30（ディテール25、マスク15）、コントラスト+30、黒-25。粒は量50、サイズ30。
- **向く被写体**：元プリセットの雰囲気を保ったまま、一段使いやすくしたいとき。
- **注意**：テクスチャと明瞭度は0。細部をもっと出したい場合は、All-Round以降を使う。

#### All-Round EI400
- **特色**：ISO 400 で撮った標準的な Tri-X。粒を持ちながら、輪郭と細部をしっかり描写する。
- **設計**：コントラスト+20と控えめで、シャドウ+20、黒-30。シャープ40、テクスチャ+10、明瞭度+8。粒は量45。
- **向く被写体**：日常のスナップ、人物、風景など幅広く。常に強いコントラストにはならない、という Tri-X の性格に沿った設定。
- **注意**：01 Standard よりシャープと粒が強め。自然さ重視なら 01 Standard が向く。

#### Push EI800
- **特色**：EI800 で撮って増感現像したイメージ。黒を深く、ハイライトを明るくして、粒も増える。
- **設計**：コントラスト+30、黒-38、白+18、シャープ42、粒60。
- **向く被写体**：夕方、室内、曇りの街などの、やや暗い場面。
- **注意**：シャドウ+12と控えめなので、暗部を起こしたいときは別途持ち上げる。

#### Push EI1600
- **特色**：EI1600 で撮って増感現像したイメージ。低照度向けで、4種の中で粒とコントラストが最強。
- **設計**：コントラスト+40、黒-45、ハイライト-25、白+20、粒量75、サイズ36。シャープ45。
- **向く被写体**：夜、暗い室内、ストリート。
- **注意**：暗部が重く、粒もかなり目立つ。人物の肌には荒く出やすいので、粒量を 50〜60 に下げると扱いやすい。

#### 02 Pushed と Push EI800 / EI1600 の違い
- 02 Pushed：コントラスト+45と強く、粒量70。スナップ・夜景・建築向けの「力強い表現」を狙った版。
- Push EI800 / EI1600：撮影感度の段階（EI800、EI1600）に対応した版。粒は EI1600 が最も強い。
- 迷ったら、強い表現を狙うなら 02 Pushed、実際に暗い場面で増感を再現したいなら Push EI800 / EI1600。

## 4. 使い分けガイド

### 被写体・目的別
| 撮りたいもの | まず選ぶ | 次の候補 |
|---|---|---|
| 迷ったとき | 01 Standard | 03 Soft |
| 元プリセットの雰囲気を保ちたい | Refined | All-Round EI400 |
| 細部と粒を両立させたい（ISO 400 風） | All-Round EI400 | Refined |
| 人物（自然に） | 03 Soft | 01 Standard |
| 人物（強い表現） | Hard Flash | 02 Pushed |
| 日常・ポートレート（レトロ） | Vintage Print | 03 Soft |
| 夜景・ストリート | 02 Pushed | Push EI1600 |
| 夕方・室内・曇りの街 | Push EI800 | 02 Pushed |
| 暗い室内・夜の粒感重視 | Push EI1600 | Deep Shadow |
| 都市・建築（重厚） | Deep Shadow | 02 Pushed |
| 建築（穏やか） | 03 Soft | 01 Standard |
| 風景（細部重視） | Fine Grain | 01 Standard |
| 空・雲が主役 | Red Filter | Deep Shadow |
| 静物 | Fine Grain | 03 Soft |

### 光の条件別
- **曇り・柔らかい光**：03 Soft、Vintage Print
- **晴れ・硬い光**：01 Standard、Red Filter
- **暗い・低照度**：Push EI800 / EI1600、02 Pushed、Deep Shadow
- **直射フラッシュ・夜の人物**：Hard Flash

### 白黒版か Desat 版か
- 写真がカラーでも白黒でも使いたい → 白黒版
- カラーに戻す可能性を残したい、プロファイルを保ちたい → Desat 版
- 色別の効きを最大限使いたい（空の濃度など）→ 白黒版が安定

## 5. 使い方のコツ

1. **露出を先に整える**：Tri-X 系は露出で仕上がりが変わる。適用前に露出を合わせておく。
2. **適用量（Amount）で強さを調整**：プリセットの強さはスライダーで0〜200に変えられる。
3. **黒と粒を最後に微調整**：黒（暗部の沈み）と粒量は、写真ごとに差が出やすい。
4. **重ねがけは避ける**：プリセットは設定を上書きする。2種を合わせたい場合は、スライダーで数値を寄せる。
5. **書き出しサイズに注意**：粒は縮小書き出しで見えにくくなる。確認は等倍でも行う。

## 6. 導入手順（Lightroom Classic）

1. 現像モジュール → 左のプリセットパネルの「＋」→「プリセットを読み込む」
2. .xmp ファイルを選んで読み込む
3. グループ「Black White」に登録される
4. 写真を選んでクリックで適用

モバイル版の Lightroom でも .xmp を読み込めます。
