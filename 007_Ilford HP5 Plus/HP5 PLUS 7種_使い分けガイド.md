# HP5 PLUS 7種 使い分けガイド

ILFORD HP5 PLUS（ISO400・ニュートラルな階調・広いラチチュード・粒子がはっきり出る）を土台にした7種です。
2・3番は単なるコントラスト違いではなく、**Standard＝基本の性格 / Documentary＝黒の力強さ / Soft Tone＝中間調の豊かさ**をそれぞれ主役にしています。

## 一目でわかる選び方

| 撮影・仕上げたい雰囲気 | 選ぶプリセット |
|---|---|
| 迷ったらまずこれ。人物・街・風景なんでも | 01 Standard |
| 力強く、骨太に。建築・街角スナップ・報道風 | 02 Documentary |
| 柔らかく、グレーを豊かに。人物・自然・室内・静物 | 03 Soft Tone |
| 暗い場面を荒く、強く。増感フィルム風 | 04 Pushed 1600 |
| 夜景・暗所で、暗部の存在感を残したい | 05 Night & Shadow |
| 古いプリントのような、浮いた黒とくすんだ白 | 06 Vintage Print |
| 明るく軽やかな階調。ハイキー | 07 High Key |

---

## 01｜HP5 PLUS Standard
- **特色**: 標準的な描写。中程度のコントラストでハイライトとシャドウの階調を残し、自然な粒状感。
- **主な設定**: コントラスト+8 / ハイライト-25 / シャドウ+14 / 黒-8 / 明瞭度+3 / テクスチャ+4 / 粒子38 / 周辺光量-8
- **使いどころ**: 人物、街並み、風景など幅広く。他のプリセットを選ぶ前の基準として。
- **ひとこと**: 迷ったらこれで始め、物足りない方向に応じて他の版へ移るのが近道です。

## 02｜HP5 PLUS Documentary
- **特色**: 報道・ドキュメンタリー風の力強さ。黒を深く締め、中間調のコントラストと明瞭度を強めて粒状感もやや強め。
- **主な設定**: コントラスト+26 / 黒-32 / 白+10 / 明瞭度+22 / テクスチャ+14 / Dehaze+4 / 粒子50 / 周辺光量-15。青を暗く落とすGray Mixer（青-22）。
- **使いどころ**: 建築、街角、人物スナップ。光と影の差がはっきりした場面。
- **注意**: 逆光や強いコントラストの場面では黒が潰れやすいので、シャドウを+10前後まで上げて調整を。

## 03｜HP5 PLUS Soft Tone
- **特色**: 柔らかな光と豊かなグレー。コントラストを抑え、シャドウを潰さず、ハイライトを柔らかくする。
- **主な設定**: コントラスト-8 / ハイライト-35 / シャドウ+26 / 黒+8 / 明瞭度-8 / テクスチャ-6 / 粒子26 / 周辺光量-4。カーブで黒をわずかに持ち上げ。
- **使いどころ**: 人物、自然、室内、静物。曇天や窓際の柔らかい光。
- **注意**: 全体が眠く見える場合は、コントラストを+5〜+10ほど足すとちょうどよくなります。

## 04｜HP5 PLUS Pushed 1600
- **特色**: 高感度増感のイメージ。荒く大きな粒子と強いコントラスト。
- **主な設定**: コントラスト+32 / 黒-26 / 白+12 / 粒子78（サイズ36・粗さ74）/ 明瞭度+10 / シャープネス20 / 周辺光量-10。
- **使いどころ**: 暗めの室内、夕暮れ、ライブ、荒々しいスナップ。
- **注意**: 粒子が強いので、低解像度の書き出しやSNS用の縮小では効果が変わります。粒子量は等倍付近で確認を。

## 05｜HP5 PLUS Night & Shadow
- **特色**: 夜景・暗所向け。暗部を完全には潰さず、存在感のある黒として残す。
- **主な設定**: ハイライト-45 / シャドウ+18 / 黒-24 / 白-10 / 明瞭度+12 / Dehaze+8 / 粒子56 / 周辺光量-20。低域を沈めるカーブ。
- **使いどころ**: 街灯のある夜景、ネオン、暗い路地。光源があるシーン。
- **注意**: 光源が白飛びしやすいので、ハイライトと白で調整。ノイズが多い場合は粒子を-10ほど下げる。

## 06｜HP5 PLUS Vintage Print
- **特色**: 古いモノクロプリントのような柔らかな黒と白。黒は持ち上がり、白は純白まで届かない。
- **主な設定**: コントラスト-4 / 黒+10 / 白-8 / 粒子34（サイズ38）/ 周辺光量-12。カーブで黒20・白236。ごく淡い暖色の色味付き（ハイライトSat10・影Sat6）。
- **使いどころ**: 古い街並み、ポートレート、ノスタルジックな作品。
- **注意**: 6種のうちこれだけ色味が入ります。完全なニュートラルにしたい場合は、カラーグレーディングの彩度を0に。

## 07｜HP5 PLUS High Key
- **特色**: 明るい階調を中心にした軽やかなモノクロ。
- **主な設定**: 露出+0.6 / シャドウ+40 / 白+20 / 黒+10 / ハイライト-30 / 粒子22 / 周辺光量なし。カーブで中間調を持ち上げ。
- **使いどころ**: 明るい室内、白い被写体、逆光の人物、雪景色。
- **注意**: 露出補正を含むので、元写真が明るい場合は露出を戻してください。ハイライトが飛ぶ場合は白を下げる。

---

## 共通の使い方
- 全部モノクロ処理です。カラー素材に適用すると自動でモノクロになります。
- 明るさは露出（07のみ+0.6を含む）で合わせてから、コントラストや黒で微調整するとブレにくいです。
- 粒状感や周辺光量は出力サイズで見え方が変わります。等倍と全体表示の両方で確認してください。
- Gray Mixerは青系の暗さ（空の濃さ）を決めます。空を明るく残したい時は青を+方向に動かします。
- 2つ重ねて使うより、1つ選んで微調整する方が破綻しにくいです。
