# Kodak Gold 200 プリセット集

Kodak Gold 200(ISO 200 / daylight / C-41)の特性をLightroom向けに再現した、全8種のプリセットです。

**基準にした特性**: 暖かみのある色彩と鮮やかさ、微粒子、高いシャープネス、露出許容範囲(アンダー2段〜オーバー3段)。黄色・オレンジが映え、緑や青も色の存在感を残す描写を目指しています。

**共通の方針**
- 黄色を強くしすぎず、全体を黄ばませない
- 肌色をオレンジに転ばせない
- 緑を単純に黄色へ寄せない
- 青空の青を残し、暖色一辺倒にしない
- ハイライトは白く飛ばさず、色を残す
- 粒子は控えめに(微粒子)

> 公式仕様が特定の黄色や肌色の色相を保証しているわけではありません。実際の仕上がりは露出・現像・スキャン・プリントで変わるため、あくまで「Gold 200らしさ」の解釈です。

## 008_Kodak Gold 200

### Kodak Gold 200 Refined
元のXMPの方向性を保ったまま、問題点だけを直した修正版です。
- 緑の色相(-22→-16)、ハイライトの青カーブ(238→244)、ハイライトのオレンジ彩度(22→16)を調整し、黄ばみと緑被りを軽減
- シャドウの色相を黄緑寄りから黄寄りへ(100→70)
- **使いどころ**: 元のプリセットの雰囲気をそのまま使いたいとき

### Kodak Gold 200 Revised
Webで調べた公式特性(鮮やかな彩度・暖かい黄金色・細粒・広いラチチュード)を反映した版です。
- ハイライト-22、白-6でオーバー側の粘りを表現
- 色温度+5、赤・オレンジ・黄の彩度を上げた暖色寄り
- **使いどころ**: Refinedより暖かく鮮やかにしたいとき。黄みがやや強いので、写真によっては色温度を下げてください

### Kodak Gold 200 Revised 2
Revisedの黄みを抑え、色の存在感・微粒子・シャープネスを追加した版です。
- 色温度+3、Vibrance +8、Saturation +3
- 粒子は量18 / サイズ22 / 粗さ55、シャープネス45 / ディテール25 / テクスチャ+5
- 肌(オレンジ彩度+8)、緑(色相-6・彩度+2)、青(彩度+2・輝度-2)をそれぞれ保護
- **使いどころ**: 8種の中で最も「基本形」に近い、仕様を丁寧に反映した版。STANDARDの前身

## 009_Kodak Gold 200 Series

調整方向の一覧(Revised 2を基準にした相対的な方向です)

| 項目 | STANDARD | GOLDEN SUN | GOLDEN MEMORY |
|---|---|---|---|
| 色温度 | 暖色寄り(+3) | より暖色(+8) | 暖色寄り(+4) |
| 彩度 | 自然に鮮やか | 高め | やや控えめ |
| コントラスト | 標準(+4) | やや強め(+12) | 弱め(-10) |
| ハイライト | 自然(-20) | 暖色を強調(-16) | 柔らかく(-30) |
| シャドウ | 適度に残す(+12) | やや締める(+6) | 持ち上げる(+28) |
| 黒レベル | 標準(+3) | やや深め(-4) | 浅め(+14) |
| 明瞭度 | 標準(0) | やや高め(+6) | やや低め(-8) |
| 粒子 | 控えめ(16) | 控えめ(16) | 控えめ(18) |

### 01 Kodak Gold 200 STANDARD
Gold 200らしい暖色系の発色と鮮やかさを、自然なバランスで再現する基準版です。
- 黄色・オレンジの温かさを残しつつ、緑や青も自然に表現
- **使いどころ**: 日中の自然光全般。迷ったらここから始めて、他の版へ展開

### 02 Kodak Gold 200 GOLDEN SUN
ゴールド系の色彩と日差しを強調した版です。
- ハイライトのカラーグレーディングで暖色を強め、コントラストと明瞭度を上げて光の印象を強調
- 青の彩度は残しているので、空まで黄色くなりません
- **使いどころ**: 夏の風景、夕方の光、逆光や斜光。曇天や室内では暖色が強く出すぎることがあります

### 03 Kodak Gold 200 GOLDEN MEMORY
コントラストを穏やかにし、少し褪せた色彩と柔らかな階調を出した版です。
- 黒を浅くし(カーブ黒点24)、シャドウを持ち上げ、ハイライトを-30で柔らかく
- 彩度-8、明瞭度-8でレトロな雰囲気
- **使いどころ**: 日常のスナップ、人物写真。強い印象より「思い出のような」やさしい仕上がりに

### A. Kodak Gold 200 GREEN SUMMER
緑の表現を中心に調整した版です。
- 緑は色相-4で黄色に寄せすぎず、彩度+10・輝度-8で深みを出す
- 黄色(色相-6)と緑を分離し、アクアも少し緑寄りに整える
- オレンジの彩度は抑えめ(+4)
- **使いどころ**: 植物、森林、夏の風景

### B. Kodak Gold 200 PORTRAIT GOLD
人物写真向けの版です。肌の赤みと黄みを抑えつつ、Gold 200らしい暖かさを維持します。
- 赤の彩度-6、黄の彩度-4、オレンジは輝度+8で明るく
- 暖かさはハイライトのグレーディングで維持
- 明瞭度-6、テクスチャ-4、粒子12、シャープネス30で肌を柔らかく
- **使いどころ**: ポートレート、スナップの人物。肌が赤い・黄色い被写体に特に有効

### C. Kodak Gold 200 GOLDEN NIGHT
夜景・室内向けの版です。暖色照明を生かし、暗部の色の濁りを抑えます。
- シャドウ+20、黒0で暗部が浮きも潰れもしない
- シャドウのグレーディングを黄緑ではなく青寄りのニュートラル(色相230)にして、色の濁りを抑制
- オレンジは彩度+6・輝度+6、ハイライト-30で光源の白飛びを抑制
- ノイズ低減(輝度10 / カラー30)入り
- **使いどころ**: 夜景、室内、暖色の電球・街灯

> **注意**: Gold 200は昼間用のISO 200フィルムです。GOLDEN NIGHTは夜間撮影を忠実に再現するものではなく、デジタル写真向けの創作的な解釈です。

## 使い方のコツ

1. **まず STANDARD を当てる**。そこから暖かさを足すなら GOLDEN SUN、柔らかくしたいなら GOLDEN MEMORY
2. 色温度は写真ごとに差が出ます。黄ばむ場合は色温度を下げ、青空が濁る場合は青の彩度を少し上げてください
3. プリセット適用後は、露出とホワイトバランスだけ先に整えてから比較すると違いが分かりやすいです
4. 粒子(微粒子)は全種で控えめです。もっとフィルムらしくしたい場合のみ、粒子量を+5〜10程度で調整
5. 肌がオレンジに寄る場合は、オレンジの彩度か赤の彩度を少し下げるか、PORTRAIT GOLDを使ってください
