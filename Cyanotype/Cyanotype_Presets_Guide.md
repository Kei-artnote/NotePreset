# Cyanotype プリセット 特色・使い方ガイド

全9種（グループ名: `Cyanotype`）。すべて白黒変換（Monochrome）＋カラーグレーディング＋トーンカーブで青を作っています。HSLだけで青くしていないため、元写真の色に左右されにくい設計です。

> 注意: 設定値は設計意図に基づくもので、実際の写真での見え方はLightroomで確認・調整してください。

---

|---|---|---|---|---|
| Cyanotype Classic v2 | 元プリセットの改良版 | 汎用 | 標準 | 中 |
| 01 Classic Cyanotype | 最も伝統的。濃いプルシアンブルー＋白 | 迷ったらこれ | 標準 | 中 |
| 02 Deep Cyanotype | 深い青と強いコントラスト | 建築・夜景・樹木・風景 | 暗め | 強 |

## 2. 各プリセットの特色

### Cyanotype Classic v2（元プリセットのブラッシュアップ版）
- **元の問題点**: ハイライト-25で白が灰色になる／黒-20で暗部が純黒に潰れる／ハイライトにほぼ色がなく白〜淡青の階調がない／トーンカーブ未使用／グレーミキサー未設定。
- **改善点**: カーブで黒を12まで持ち上げ（暗部が黒でなく濃紺になる）、ハイライトに淡い青（彩度10）を追加、グレーミキサーで青系を少し暗くして元色による振れを抑制。
- **使いどころ**: 元のプリセットと同じ感覚で使いたいとき。粒状とクラリティが01よりやや強め。

### 01 Classic Cyanotype
- **特色**: 深いプルシアンブルーと白いハイライト。シャドウ色相224・彩度60、ハイライトはほぼ白（255維持）。
- **使いどころ**: どの写真でも外しにくい基準。シリーズの標準として使い、他は用途で選ぶ。

### 02 Deep Cyanotype
- **特色**: 暗部を引き締め、青の深みを強調。S字カーブ、黒-25、クラリティ+15、デヘイズ+10、周辺減光-18。グレーミキサーで青・シアン・緑を暗くするので空や木々が締まる。
- **使いどころ**: 建築、夜景、樹木、風景。
- **注意**: 暗い写真では潰れやすい。露出を+0.3〜+0.5上げるか、シャドウを+10〜+20にする。

### 03 Soft Cyanotype
- **特色**: 淡い青と柔らかな階調。露出+0.25、シャドウ+30、黒+10、カーブの黒を34に持ち上げ、クラリティ-10。
- **使いどころ**: 植物、人物、静物。肌や花びらを硬くしたくないとき。
- **注意**: 全体が眠くなりやすい。白が足りなければ白レベルを+10程度足す。

### 04 Blueprint
- **特色**: 青の彩度を高めに均一化し、クラリティ+25・テクスチャ+20で線とエッジを立てる。ハイライトは冷たい水色寄り。
- **使いどころ**: 建築、構造物、機械、直線の多い被写体。
- **注意**: 本物の青焼き（青地に白線）の反転再現ではなく、近似表現。細部が多い写真ほど映える。

### 05 Indigo Cyanotype
- **特色**: シャドウ・中間調を色相230前後の藍色寄りに。ハイライトは暖かい紙白（色相45）。粒状を大きく粗くして和紙のざらつき感を出す。
- **使いどころ**: 和の風景、庭、布、器、藍染めを連想させる被写体。

### 06 Aged Cyanotype
- **特色**: 彩度を抑え、ハイライトを暖色の紙色に。カーブで黒を24持ち上げ白を244に抑えて退色感。粒状強め、周辺減光-12。
- **使いどころ**: 古い街並み、廃墟、レトロなポートレート。

### 07 High Key Cyanotype
- **特色**: 露出+0.6、シャドウ+35、黒+15、カーブで黒を40まで持ち上げ、白と中間調の面積を広げる。彩度は低め。
- **使いどころ**: 白い花、葉、逆光の植物など軽やかな写真。
- **注意**: 暗い・コントラストの強い元画像には不向き。明るい元画像で使うこと。白飛びが出たら露出を下げる。

### 08 Cinematic Cyanotype
- **特色**: シャドウは深い青（色相228・彩度65）、中間調は青緑寄り（色相190）、ハイライトはわずかに暖色（色相40）。S字カーブ、周辺減光-20。
- **使いどころ**: 街、人物、物語性のある風景。
- **注意**: 中間調の青緑は人物の肌が不自然に見えることがある。中間調の彩度を20前後に下げると和らぐ。

## 3. 使い分けの指針

**被写体で選ぶ**
- 風景・建築・夜景 → 02 Deep（硬めにしたくなければ 01）
- 植物・花 → 03 Soft、白が多ければ 07 High Key
- 人物 → 03 Soft、または 06 Aged
- 和の被写体 → 05 Indigo
- 線・構造物 → 04 Blueprint
- 雰囲気重視の街・人物 → 08 Cinematic

**元写真の明るさで選ぶ**
- 暗い・コントラストが強い → 02 / 08 は潰れやすいので 01 や 03
- 明るい・フラット → 07 や 03
- 標準 → 01

**仕上がりの雰囲気で選ぶ**
- 伝統的 → 01 / Classic v2
- 力強い → 02
- 繊細 → 03 / 07
- 懐古 → 06 / 05
- モダン・映画的 → 08 / 04

## 4. 使い方（Lightroom）

1. プリセットを読み込む（Lightroom Classic: プリセットパネルの「+」→「プリセットを読み込み」。XMPを選択）。
2. 写真に適用する。白黒に変換されるため、元のカラーは失われる（元に戻す場合は履歴かリセット）。
3. 仕上げの調整順（おすすめ）:
   1. 露出（写真全体の明るさを合わせる）
   2. 白レベル・黒レベル（白をどこまで白にするか／暗部を沈めるか）
   3. 白黒ミックス（グレーミキサー）で空・葉・肌などの明暗配分
   4. カラーグレーディングの彩度（青の濃さ）
   5. 粒状・周辺減光
4. 「適用量（Amount）」スライダーに対応しています。強すぎると感じたら下げる。

---

## 5. 調整のコツ

| 変えたいこと | 触る場所 |
|---|---|
| 青を濃くしたい／薄くしたい | カラーグレーディング 中間調・シャドウの彩度 |
| 白をもっと白くしたい | 白レベル、ハイライトの彩度を下げる |
| 暗部を濃紺にしたい（黒にしたくない） | トーンカーブの左下の点（黒の持ち上げ） |
| 空をより暗く | グレーミキサー「ブルー」「アクア」を下げる |
| 肌・花を明るく | グレーミキサー「オレンジ」「レッド」を上げる |
| 緑（葉）を明るく／暗く | グレーミキサー「グリーン」「イエロー」 |
| 紙っぽいざらつき | 粒状（量・サイズ・粗さ） |

---

## 6. 制限事項

- 紙の繊維や塗布ムラ（ブラシ跡、縁の不均一）は通常のプリセットでは再現できません。必要ならテクスチャ素材を重ねてください（Aged と Indigo と相性がよい）。
- カラー写真を白黒変換しているため、元の色の組み合わせで明暗が変わります。グレーミキサーで調整してください。
- ビルトインのモノクロ処理を使っているため、HSLパネルは使えません（白黒ミックスで代用）。
